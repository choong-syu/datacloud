# 데이터클라우드공학과 - 채용공고 기반 직무 탐색

대학교 소개 부스에서 학생들이 CLOUD 관련 직무, 기술, 프로젝트를 직접 눌러보며 탐색할 수 있는 React 기반 인터랙티브 데이터 시각화 MVP입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 Vite가 출력하는 로컬 주소로 접속합니다.

## JSON 데이터 위치

데이터 파일은 아래 경로에서 fetch합니다.

```text
public/data/cloud_job_market_analysis_2026-05-26.json
```

앱은 먼저 표준 JSON 파싱을 시도합니다. 파일 인코딩 또는 문자열 손상으로 파싱이 실패하면 텍스트에서 직무, 기술, 그래프, 공고 URL의 핵심 필드를 복구해 데모 화면을 계속 표시합니다.

## 주요 기능

- CLOUD 루트에서 직무 노드가 펼쳐지는 React Flow 그래프
- 직무 노드 클릭 시 상세 패널 표시
- 직무 노드 더블클릭 시 기술, 프로젝트, 자격증 노드 확장/접기
- AWS, Kubernetes, DevOps 등 키워드 검색 및 관련 노드 강조
- 필수 기술, 우대 기술, 신입/주니어, 프로젝트, 자격증 필터
- 분석 표본 내 주요 기술 TOP 차트
- 직무별 공고 기반 해석, 추천 프로젝트, 근거 URL 제공
- 학생용 로드맵 타임라인

## 부스 시연 방법

1. 첫 화면에서 CLOUD 루트와 주요 직무 노드를 보여줍니다.
2. `DevOps Engineer` 노드를 클릭해 오른쪽 상세 패널을 엽니다.
3. `DevOps Engineer` 노드를 더블클릭해 AWS, Kubernetes, Docker, CI/CD 같은 기술 노드를 펼칩니다.
4. `Kubernetes` 노드를 클릭해 등장 횟수, 관련 직무, 다음 학습 기술을 보여줍니다.
5. 오른쪽 패널의 `처음 배우기` 또는 `포트폴리오 추천` 버튼으로 하단 추천 경로를 강조합니다.

## 향후 확장 아이디어

- 손상되지 않은 UTF-8 원본 JSON으로 한글 공고 설명 복원
- 직무 추천 미니 퀴즈 결과를 그래프 강조와 직접 연결
- 기술 조합 노드를 별도 타입으로 확장
- 터치스크린용 큰 버튼 모드와 자동 시연 모드 추가
- 공고 사이트 필터를 실제 공고 목록 필터링까지 연결
